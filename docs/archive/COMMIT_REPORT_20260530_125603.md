## Detailed Changes

- **Replay-protection fail-safe**: `PostgresNonceCache.use()` now throws `NonceStorageUnavailableError` on PostgreSQL `42P01` (table missing) instead of silently failing open. `appCredentialGuard` returns HTTP 503 `REPLAY_PROTECTION_UNAVAILABLE` for write methods.
- **Schema parity**: `nonces` table added to `schema.sql` so fresh DB init includes replay protection storage.
- **loop_completed event**: new speaking event type for end-of-loop signal. Required fields `duration_ms` + `prompts_count`. `getSpeakingSummary` returns `loop_completion_count`. Does not affect `approximate_duration_ms`.
- **Worker shutdown**: SIGTERM/SIGINT handled gracefully — sets flag, waits up to 10s for in-progress tick, force-exits with warning if drain times out.
- **SpeakingSummaryScreen**: StatefulWidget displays sentence count, approximate speaking time, drill loop completions. Offline fallback with retry. "Start Drill" CTA. Accessible from drawer and after drill completion.
- **Dashboard article double-encode fix**: `patchArticle` was passing `JSON.stringify(patch)` as body to `backendFetch` which then stringifies again. Fixed to `body: patch`.
- **Dashboard visibility**: `shared` removed from article creation form; only `private` and `published` remain per API contract.
- **Dashboard certificate proxy**: `/api/certificate/[id]/route.ts` proxies to backend certificate endpoint so dashboard links resolve correctly on same origin.
- **Loop health card**: ops page shows weekly loop completions, drill attempts, latest approved prompt timestamp, latest published passage timestamp with 7-day staleness warning.
- **Certificate URL**: mobile copy-link uses `https://expat8.x51.vn/exam/certificate/:id` (no `/v1/` prefix per task spec).
