## App icon exports

Use the v2 master as the source for platform icons. Keep its indigo field,
layered white pages, and mint spark. Android adaptive icons use the matching
vector foreground over a solid royal-indigo background; keep all foreground
details inside the center safe area. iOS applies its own mask, so do not
pre-round or crop its icon. Web favicon and PWA exports use the same mark and
palette at their target sizes.

## Store copy

Use `mobile/assets/store/play-store-listing.md` as the current copy source. The
brand descriptor is **Learn a little. Use it everywhere.** Keep feature art
free of text so it can be reused across languages and crops.
