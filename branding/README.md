# Expat8 brand assets

## Asset map

- `expa8-mark.svg` — refreshed square mark for app surfaces and navigation.
- `expa8-mark-mono.svg` — one-color layered-book mark for constrained surfaces.
- `expa8-lockup.svg` — mark, wordmark, and descriptor in one vector asset.
- `icons/expa8-icon-set.svg` — shared UI icon symbols.
- `release/` — current icon, feature artwork, and preserved previous artwork.
- `../BRAND.md` — canonical brand voice, palette, and usage rules.

## Usage rules

- Keep clear space at least one quarter of the mark's rendered width.
- Use royal indigo for actions and current navigation; use semantic teal for
  readable progress states and mint for the mark's spark.
- Keep the open pages white and the spark mint. The gradient belongs to the
  icon field and campaign art, not inside the mark itself.
- Do not stretch, rotate, add shadows, or place text inside the mark.
- Use the icon set for feature affordances; use semantic status colors only for
  status.
- Platform icons are exports of `release/expa8-app-icon-v2.png`; follow the
  safe-zone notes in `release/README.md`.
